সংক্ষিপ্ত বিবরণ

React Vite দিয়ে Blog Website তৈরি
টেকনোলজি:
React.js (Vite)
Tailwind CSS
JSONPlaceholder API

কাজের বিবরণ
আপনি React Vite এবং Tailwind CSS ব্যবহার করে একটি সুন্দর ও Responsive Blog Website তৈরি করবেন। Blog-এর Data JSONPlaceholder API থেকে সংগ্রহ করতে হবে।
API: https://jsonplaceholder.typicode.com/posts

Requirements
Home Page-এ সব Blog Post সুন্দর Card আকারে দেখাতে হবে।
প্রতিটি Blog Card-এ Title ও Description দেখাতে হবে।
প্রতিটি Blog-এর জন্য Details Button রাখতে হবে।
Details Button-এ ক্লিক করলে নির্দিষ্ট Blog-এর সম্পূর্ণ তথ্য দেখাতে হবে।
সুন্দর Header ও Footer তৈরি করতে হবে।
Tailwind CSS দিয়ে Responsive Design করতে হবে।
API থেকে Data Fetch করার সময় Loading এবং Error Message দেখাতে হবে।

Submission Rules: 
Git এ  পুশ করে রিপোজিটরি লিংক দিতে হবে। অবশ্যই লিংক পাবলিক রাখতে হবে। Git Link  ছাড়া যদি আপনি সরাসরি zip আকারে জমা করেন তাহলে 0 পাবেন।
